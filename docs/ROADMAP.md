# مراحل تنفيذ LiveStar

المنفذ في هذا التسليم هو المرحلة الأولى فقط. الجداول الخاصة بالمراحل اللاحقة
تمهيد للعلاقات؛ وجود جدول لا يعني اكتمال واجهته أو منطق أعماله.
التقدم مشروط بالتحقق من أساس المرحلة السابقة وتوثيق النتائج.

## المراحل ومعايير القبول

| المرحلة | التنفيذ | معيار الإكمال الأساسي |
| --- | --- | --- |
| 1. Architecture & Database | Monorepo، نموذج Prisma، ترحيلات وقيود، فحوص API، Compose، توثيق واختبارات الأساس | تطبيق الترحيلات على PostgreSQL نظيفة، اجتياز اختبارات القيود والحسابات، وفحص جاهزية حقيقي مع PostgreSQL وRedis؛ توثيق أي تحقق متعذر |
| 2. Authentication & Users | تسجيل ودخول واستعادة، تجزئة كلمات المرور، تدوير الجلسات، RBAC، التحقق من البريد والعمر، إدارة الملف والمتابعة | اختبارات تدوير وإبطال الجلسات ومنع إعادة الاستخدام وتصعيد الصلاحية؛ تدفقات البريد تحتاج مزودًا |
| 3. Web & Mobile UI | Next.js وTailwind وFlutter، عربي/إنجليزي، RTL، سمة Dark Luxury، تنقل وإتاحة | بناء فعلي للويب وAndroid وiOS، وربط الشاشات بواجهات المرحلة الثانية؛ كل ميزة لاحقة تعلن حالتها بوضوح |
| 4. Streaming & Chat | LiveKit/WebRTC، إذن الكاميرا والميكروفون، غرف ومشاهدون، WebSocket، إعجاب ومتابعة ومشاركة ومكافحة إساءة | اختبار بث بين أجهزة فعلية، رفض نشر غير مصرح، استعادة اتصال، كتم وحظر وإنهاء بث مخالف، قياس الحمل |
| 5. Gifts & Wallets | كتالوج الهدايا والصور والتأثيرات، رصيد LiveCoins، إنفاق ذري وإسناد دفعات الرصيد للهدايا | اختبارات تزامن ومنع الرصيد السالب والتكرار وثبات أسعار المعاملة؛ العملات المشتراة لا تسحب نقدًا |
| 6. Payments & Revenue | محول Web، تحقق Apple/Google، Webhooks، تسويات صافي الإيراد، تقسيم 50/50، استرداد ونزاع | sandbox لكل مزود، توقيع وإعادة إرسال الأحداث، فشل جزئي وتكرار واختبارات تسوية؛ لا تمكين فعلي قبل الموافقات |
| 7. Payouts & Admin | KYC وأهلية البلد والحساب، تعليق وإتاحة الأرباح، طلبات السحب، لوحات المشرف والمدير، سياسات مستقبلية مؤرخة | منع سحب المعلق ومراجعة المخاطر، منع الدفع المكرر، مطابقة المزود، تدقيق تغييرات الإدارة وصلاحياتها |
| 8. Security & Deployment | اختبارات شاملة وتحميل وأجهزة، مراقبة وإنذارات، HTTPS وCDN ونسخ واستعادة، CI/CD وأدلة المتاجر | استعادة مثبتة، فحص أمني وإغلاق العيوب، حدود سعة مقاسة، تجهيز إنتاج وموافقات نشر الويب والمتاجر |

مرحلة الدفع تتوقف عند البلد القانوني للشركة والبلدان المستهدفة وتوافر المزود
وسياسة المنتجات الرقمية. لا يوجد افتراض بإتاحة Stripe أو PayPal عالميًا.
على Android وiOS يُستخدم نظام المتجر للمنتجات الرقمية ما لم ينطبق برنامج
أو استثناء إقليمي مسموح ومثبت.

شاشات المرحلة الثالثة لا تعرض نجاح عمليات دفع أو رصيدًا منشأً محليًا.
أي بيانات sandbox لاحقة تُعرّف بوضوح، وتبقى منفصلة عن معاملات الإنتاج.

## اعتمادات خارجية قبل الإطلاق

- شركة وبلدان تشغيل محددة، ومزود دفع وسحب يدعمها، ومراجعة الضرائب والرسوم والتسويات.
- Apple Developer وGoogle Play Console، ومنتجات IAP معتمدة، ومفاتيح تحقق خادمية وإشعارات المتاجر.
- مزود KYC ومراجعة مخاطر وعقوبات بحسب نطاق النشاط، مع حماية بيانات الهوية.
- بريد وتخزين وCDN وبث وTURN وAPNs/FCM ومراقبة، بأسرار خارج المستودع.
- سياسات خصوصية واستخدام واسترداد وإشراف ومراجعة عمر مرتبطة ببلدان التشغيل.

ومتطلبات التشغيل في [دليل النشر](DEPLOYMENT.md).
