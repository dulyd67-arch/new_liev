# LiveStar — منصة للايفات

النطاق الحالي هو **منصة ويب بسيطة للبث المباشر**: إنشاء حساب، بدء بث بالكاميرا
والميكروفون، اكتشاف البثوث، المشاهدة، والمحادثة. الواجهة عربية افتراضيًا مع
خيار الإنجليزية، وتعمل على متصفح الكمبيوتر والهاتف.

**الرابط العام:** [افتح LiveStar](https://livestar-live-nitq.onrender.com).

نُشرت النسخة التجريبية في 2026-11-14، ونجحت 18 عملية تحقق عبر HTTPS تشمل
التسجيل والدخول وتجديد الجلسات وحمايتها. نُفذت ترحيلات قاعدة البيانات الأربع.
أُعيد تصميم الاستوديو بمعاينة تملأ الشاشة وزر «بدء LIVE» وردي، وأدوات
للكاميرا والميكروفون والمحادثة والمشاركة والمشاهدين وتأكيد إنهاء البث.
نجحت عشرة تحققات محلية للشاشة الجديدة، شملت وصول فيديو وصوت فعليين إلى
متصفح المشاهد. اختبار الوسائط السحابية من بيئة العمل مقيد بسياسة WebRTC
في متصفحها؛ يلزم تأكيد التجربة من هاتف أو شبكة خارجية.

## النشر العام بميزانية صفر

تعمل النسخة على خدمة Render Free واحدة تجمع الموقع وAPI، مع Neon Free
لقاعدة البيانات وLiveKit Cloud Build للوسائط. جرى تأكيد اختيار الخطط المجانية؛
لا يلزم دومين مدفوع. المصدر في [GitHub](https://github.com/dulyd67-arch/new_liev)،
وملف النشر هو [render.yaml](render.yaml).

قد يتأخر أول فتح لأن Render ينام عند الخمول. الحصص المجانية تحد الاستخدام،
والبريد معطّل حاليًا، لذلك لا تتوفر رسائل تأكيد البريد أو استعادة كلمة المرور.
اقرأ [دليل النشر المجاني](docs/FREE-DEPLOY.md) للحدود ونتائج التحقق وإعادة النشر؛
يشمل أيضًا أربع نتائج `high` متبقية في اعتماديات Prisma CLI.

## التشغيل المحلي في ست خطوات

المتطلبات: Node.js 22.13+ ضمن الإصدارين 22 أو 24، وnpm 10+، وDocker Compose.
نفّذ الأوامر من مجلد المشروع `livestar` باستخدام Bash.

1. جهّز متغيرات البيئة المحلية:

   ```sh
   cp .env.example .env
   source scripts/env.sh
   ```

2. ثبّت الحزم وأنشئ عميل قاعدة البيانات:

   ```sh
   npm ci
   npm run db:generate
   ```

3. شغّل خدمات التطوير:

   ```sh
   docker compose --profile media --profile mail up -d postgres redis livekit mailpit
   ```

4. طبّق الترحيلات والإعدادات المرجعية:

   ```sh
   npm run db:deploy
   ```

5. شغّل الموقع والخادم معًا:

   ```sh
   npm run dev:live
   ```

6. افتح `http://localhost:3000`، وأنشئ حسابًا ثم اختر **ابدأ بثًا**.
   اسمح للمتصفح باستخدام الكاميرا والميكروفون عند بدء المعاينة. افتح رابط
   البث في متصفح أو ملف متصفح آخر لاختبار المشاهدة. تسجيل الدخول مطلوب
   لإرسال الرسائل، والمشاهدة العامة متاحة دون حساب.

LiveKit يعمل محليًا داخل Docker بمفاتيح التطوير المرفقة. رسائل التحقق واستعادة
كلمة المرور تصل إلى Mailpit المحلي على `http://localhost:8025`.

## الملفات المهمة

| المسار | الغرض |
| --- | --- |
| `apps/web` | الموقع وواجهات الحساب والبث والمشاهدة |
| `apps/api/src/auth` و`apps/api/src/users` | الحسابات والجلسات والملفات الشخصية |
| `apps/api/src/streams` | الغرف وصلاحيات البث والمشاهدة والمحادثة |
| `packages/database/prisma` | مخطط PostgreSQL والترحيلات |
| `infra/livekit/livekit.local.yaml` | إعداد خادم الوسائط المحلي |
| `compose.yaml` | خدمات التطوير |
| `render.yaml` و`infra/docker/free.Dockerfile` | نشر مجاني بخدمة تطبيق واحدة |
| `scripts/start-free.mjs` | التحقق من الإعداد والترحيل وتشغيل الخادمين |

توثيق API على `http://localhost:4001/api/docs`، وفحص الجاهزية على
`http://localhost:4001/api/v1/health/ready`.

للبناء والتحقق:

```sh
npm run build
npm run typecheck
npm test
```

نتائج الاختبار وطريقة إعادة اختبار الفيديو في [دليل النسخة المبسطة](docs/LIVE-ONLY.md).

راجع [دليل النسخة المبسطة](docs/LIVE-ONLY.md) للتجربة وحدود التشغيل المحلي
وإعداد النشر. الكاميرا والميكروفون يحتاجان `localhost` أو HTTPS؛ وللاستخدام
من أجهزة خارجية يلزم عنوان LiveKit قابل للوصول وإعداد HTTPS/WSS وICE/TURN.

## العمل السابق

حُفظ الكود السابق والوثائق التاريخية. تطبيق Flutter وحزم المحاسبة والهدايا
والمدفوعات ليست جزءًا من نطاق نسخة اللايفات الحالية. توثيق
[المرحلة الأولى](docs/PHASE1-VALIDATION.md) و[المصادقة](docs/PHASE2-VALIDATION.md)
و[الخطة السابقة](docs/ROADMAP.md) يشرح المسار السابق، ولا يمثل قائمة ميزات
النسخة المبسطة أو ادعاء اكتمال المنصة القديمة.
